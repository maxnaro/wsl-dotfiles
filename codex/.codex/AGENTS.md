# Delegation

Use your judgment to spawn subagents when delegation improves speed, quality, or context management. This is a standing request to delegate suitable work; no separate request or confirmation is needed for each task. Prefer delegation for independent investigations, implementation tasks, and reviews. Handle small or tightly dependent tasks directly. Give each subagent a bounded task, coordinate shared files, and review its results. Remain responsible for integration and verification. Respect explicit task restrictions, available tools, and higher-priority instructions.
